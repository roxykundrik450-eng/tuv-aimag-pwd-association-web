# Төв аймгийн хөгжлийн бэрхшээлтэй иргэдийн холбоо — Вэбсайт

**Tuv Aimag Association of Persons with Disabilities — Website**

Улсын бүртгэлийн **8136629** дугаартай, 2014 онд байгуулагдсан,
ашгийн төлөө бус төрийн бус байгууллагын албан ёсны вэбсайт.

## Технологи / Tech stack

- **GOV.UK Frontend v5.11.0** (`assets/css/govuk-frontend-5.11.0.min.css`) —
  нээлттэй эх, **MIT лиценз**, [alphagov/govuk-frontend](https://github.com/alphagov/govuk-frontend)
- Сервер, build процесс, JavaScript хамаарал **шаардлагагүй**
- `assets/css/tuv.css` — GOV.UK-д байхгүй зүйлсийг (зургийн компонент) нэмсэн жижиг давхарга
- Вэб фонт ашиглаагүй (GOV.UK-ийн GDS Transport нь нээлттэй биш;
  системийн фонт руу автоматаар шилжинэ)

### Хүртээмж

GOV.UK Frontend нь хөгжлийн бэрхшээлтэй хэрэглэгчидтэй хамт туршигдсан,
WCAG 2.2 түвшинд нийцүүлэн бүтээгдсэн дизайны систем. Энэ нь хөгжлийн
бэрхшээлтэй иргэдийн байгууллагын вэбсайтад хамгийн чухал үндэслэл.

## Зургууд / Photographs

Бүх зураг **CC0 / нийтийн өмч** лицензтэй (Викимедиа Коммонс) — өөрөөр хэлбэл
**зохиогчийн эрхийн шаардлага байхгүй**, тиймээс сайт дээр нэрийн жагсаалт
эсвэл лицензийн хуудас шаардлагагүй.

- Зөвхөн CC0 / Public Domain / PDM хүлээн авна. **`by` агуулсан лиценз
  (CC BY, CC BY-SA), NC, ND бүгд хасагдана** — `tools/harvest-cc0.py` шалгана.
- Сэдэв нь байгууллагын үйл ажиллагаатай шууд холбоотой: хүртээмж (налуу зам,
  тактиль хучилт), брайль, дохионы хэл, нөхөн сэргээх дасгал, хамтын уулзалт,
  мөн Зуунмод орчмын орон нутгийн дүр зураг.

**Анхааруулга:** CC0 лиценз нь зөвхөн *эрхийн* асуудлыг шийднэ. Зураг дээрх
хүмүүс нь холбооны гишүүн, үйлчлүүлэгч **биш** — байгууллагын өөрийн гэрэл
зургийг авмагц солих нь зүйтэй.

## Агуулгын зарчим

Сайт дээр зөвхөн байгууллагын тухай, баталгаажих боломжтой мэдээлэл байна:
бүртгэлийн мэдээлэл, үйл ажиллагааны чиглэл, хийсэн ажил, холбоо барих.

- **Мэдээлэл байхгүй бол тухайн хэсгийг огт оруулахгүй** — «хүлээгдэж байна»,
  «зураг байрлуулаагүй», «эх сурвалж: …» гэх мэт тайлбар бичихгүй. Ийм тайлбар
  нь байгууллагын сайт биш, аудитын тайлан мэт харагддаг.
- Гадаад эх сурвалж, бусад байгууллагын холбоос, сайтын техникийн тайлбар
  (ашигласан CSS, зургийн лиценз) **нийтийн хуудсанд орохгүй**.
- Таамагласан тоо, огноо, үйл ажиллагаа, хүний нэр **хэзээ ч бичихгүй**.

## Хөгжүүлэлт / Development

Локал урьдчилан харах:

```bash
python3 -m http.server 8000
# дараа нь http://localhost:8000 нээнэ үү
```

Хуудсуудыг дахин үүсгэх (нэгдсэн header/footer-тай тул гараар засах шаардлагагүй):

```bash
python3 ../tools/build-site.py ../site
```
