# Төв аймгийн хөгжлийн бэрхшээлтэй иргэдийн холбоо — Вэбсайт

**Tuv Aimag Association of Persons with Disabilities — Website**

Төв аймгийн хөгжлийн бэрхшээлтэй иргэдийн холбооны албан ёсны вэбсайт.
2014 онд байгуулагдсан, улсын бүртгэлийн **8136629** дугаартай,
ашгийн төлөө бус төрийн бус байгууллага.

---

## Хуудаснууд / Pages

| Хуудас | Файл | Агуулга |
|--------|------|---------|
| Нүүр | `index.html` | Эрхэм зорилго, үйл ажиллагааны чиглэлүүд, түүх, арга хэмжээ, хандив |
| Бидний тухай | `about.html` | Эрхэм зорилго, үнэт зүйлс, замнал, удирдлага |
| Үйл ажиллагаа | `events.html` | Удахгүй болох арга хэмжээ, үйл ажиллагааны чиглэлүүд |
| Холбоо барих | `contact.html` | Хаяг, холбоо барих мэдээлэл, маягт |

## Технологи / Tech Stack

- **HTML5** — семантик тэмдэглэл, ARIA шошго, хүртээмжтэй
- **CSS3** — design tokens (CSS custom properties), Grid, Flexbox
- **Vanilla JavaScript** — фрэймворкгүй, build шатгүй
- **Фонт** — Inter + Noto Sans (кирилл) + DM Mono

Сервер, build процесс шаардлагагүй. `index.html`-ийг хөтчөөр шууд нээнэ үү.

## Өнгө / Colors

Бүх өнгө `assets/css/base.css` файлын `:root` дотор design token хэлбэрээр тодорхойлогдсон:

```css
--forest-light: #1A6B8A;   /* Брэнд — хөх-цэнхэр */
--forest:       #123F55;   /* Гүн цэнхэр */
--terracotta:   #E08A2E;   /* Онцлох — улбар шар */
--sage:         #6FA8BF;   /* Зөөлөн акцент */
--cream:        #F7F4EF;   /* Арын дэвсгэр */
```
